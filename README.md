# Sistema de detección de fatiga

El proyecto detecta señales visibles asociadas con fatiga mediante una cámara:
ojos cerrados, bostezos y cabeceos.

El código se encuentra en `detector-fatiga/` y utiliza Python, OpenCV, MediaPipe
y Flask.

```powershell
cd detector-fatiga
.\.venv\Scripts\python.exe app.py
```

Abra `http://127.0.0.1:5001`.
